# Спецификация требований к веб-приложению интернет-магазина одежды и товаров для активного отдыха

## О проекте

Проект представляет собой веб-приложение интернет-магазина одежды и товаров для активного отдыха. 

Система позволяет пользователю просматривать каталог товаров, искать товары и выбирать их по категориям, изучать информацию о товаре и добавлять позиции в заказ. При оформлении заказа пользователь указывает контактные и адресные данные, выбирает способ оплаты и получения уведомлений о статусе заказа. 

В приложении предусмотрены основные процессы оформления заказа: работа с корзиной, указание количества товаров, расчёт стоимости заказа, выбор способа оплаты, передача данных для доставки и отправка подтверждения заказа по SMS или электронной почте.

В рамках работы существующая версия спецификации была дополнена аналитическими артефактами, необходимыми для дальнейшего проектирования базы данных и разработки приложения.

## Задача

Дополнить спецификацию требований недостающими артефактами и привести описание требований и данных к единой структуре.

Основные задачи:

- актуализировать существующую спецификацию требований;
- разработать логическую модель данных в нотации Crow’s Foot;
- привести модель к третьей нормальной форме (3НФ);
- дополнить спецификацию логической моделью;
- разработать словарь данных;
- связать структуру данных с требованиями и бизнес-правилами системы.

## Мой вклад

### Актуализация требований 

Дополнила и структурировала спецификацию первой версии приложения:

- границы проекта и назначение системы;
- классы пользователей;
- пользовательские сценарии (Use Case);
- функциональные требования;
- требования к данным;
- требования к внешним интерфейсам;
- атрибуты качества;
- глоссарий;
- бизнес-правила.

### Логическая модель данных

Разработала логическую ER-модель данных в нотации Crow’s Foot.

В модели выделила основные сущности предметной области, определила связи между сущностями и их кардинальности. Привела модель к третьей нормальной форме (3НФ) для устранения избыточности и корректного представления данных.

### Словарь данных

Разработала словарь данных на основе требований и логической модели.

Для основных элементов определила:

- описание;
- состав или тип данных;
- длину;
- допустимые или примерные значения.

Словарь позволяет сопоставить элементы логической модели с конкретными данными, используемыми системой.

## Результат

Подготовлена единая спецификация требований, объединяющая пользовательские сценарии, функциональное описание системы, бизнес-правила и структурированное представление данных.

Итоговая модель включает 4 основные сущности (сущность "Пользователь" не выделена, т.к. не было задачи выделять личный кабинет пользователя и пр.) и их взаимосвязи, нормализована до 3НФ и дополнена словарём данных.

Набор подготовленных артефактов формирует основу для дальнейшего проектирования базы данных и реализации приложения.
